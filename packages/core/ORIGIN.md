# Origin and provenance

The initial Effective Protocol View operation was extracted on 2026-08-31 from
`scripts/mcpdesc-views.mjs` in
`https://github.com/mcpdesc/mcpdesc-specification` and rewritten as an
experimental TypeScript package API.

The normative behavior is grounded in MCP Description `0.8.0-draft.4`, Section
4.13. The package uses `@mcpdesc/validator` as its conformance authority and
does not copy validator semantic rules.
